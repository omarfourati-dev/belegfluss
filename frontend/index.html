Worum es geht

Was ist Belegfluss?

Viele kleine Firmen tippen Lieferant, Rechnungsnummer, Beträge und IBAN aus Eingangsrechnungen noch von Hand in die Buchhaltung. Das kostet Zeit und öffnet die Tür für Fehler und Betrug – etwa wenn eine gefälschte Rechnung mit geänderter Bankverbindung durchrutscht.

Belegfluss ist ein Rechnungseingang, der genau diesen Schritt übernimmt: Er liest jede Rechnung in strukturierte Daten aus, prüft sie auf typische Fehler und führt sie durch eine Freigabe mit klaren Rollen. Seit 2025 müssen Unternehmen in Deutschland E-Rechnungen empfangen können – Belegfluss liest diese Formate direkt und braucht dafür keine KI.

So funktioniert's

Drei Wege, eine Rechnung zu lesen

Belegfluss nimmt immer die genaueste und günstigste Quelle, die eine Rechnung hergibt. Das Auslesen läuft im Hintergrund; der Status erscheint live in der Oberfläche.

Ohne KI

E-Rechnung

XRechnung (UBL 2.1 und CII), ZUGFeRD und Factur-X – als XML-Datei oder eingebettet im PDF. Die Felder werden exakt übernommen, ohne Ratespiel und ohne Kosten für KI-Aufrufe.

Sprachmodell

PDF mit Text

Der Text des PDFs geht an ein Sprachmodell. Über Spring AI kommt die Antwort direkt als typisiertes Java-Objekt zurück: Lieferant, Rechnungsnummer, Datum, Netto, Umsatzsteuer, Brutto, IBAN.

Vision-Modell

Scan oder Foto

Hat das PDF keine Textebene, rendert Belegfluss die ersten Seiten als Bild und lässt sie von einem Vision-Modell lesen. Stimmt etwas nicht, lassen sich alle Felder von Hand korrigieren.

Automatische Prüfungen

Fehler auffallen lassen, bevor Geld fließt

Nach dem Auslesen prüft Belegfluss jede Rechnung. Warnungen blockieren nichts, aber wer eine Rechnung mit Warnung freigibt, muss begründen, warum.

  • Dublette

    Gleicher Lieferant und gleiche Rechnungsnummer schon vorhanden.

  • Beträge

    Netto plus Umsatzsteuer ergibt nicht den Bruttobetrag.

  • Steuersatz

    Umsatzsteuersatz passt zu keinem üblichen deutschen Satz.

  • IBAN ungültig

    Die Prüfziffer der IBAN stimmt nicht (Modulo 97).

  • IBAN geändert

    Ein bekannter Lieferant nennt plötzlich eine andere Bankverbindung – ein klassisches Zeichen für Rechnungsbetrug.

Rollen & Freigabe

Vier Augen, klare Zuständigkeiten

Wer eine Rechnung hochlädt oder ihre Felder zuletzt geändert hat, darf sie nicht selbst freigeben. So kann niemand allein eine IBAN austauschen und die Zahlung durchwinken.

Jeder Schritt – Upload, Auslesen, Korrektur, Freigabe, Ablehnung, Buchung – landet mit Person und Zeitpunkt im Audit-Trail. Gebuchte Rechnungen exportiert die Buchhaltung als CSV im DATEV-ähnlichen Format.

Eine offene Registrierung gibt es deshalb bewusst nicht: Benutzer und Rollen legt der Admin an.

Technik

Gebaut wie ein echtes Produkt

Backend

Java 21 und Spring Boot 3. Spring AI für strukturierte Ausgaben und Vision, Spring Security mit JWT und Rollenhierarchie, PostgreSQL mit Flyway-Migrationen, PDFBox. Hintergrundverarbeitung auf virtuellen Threads.

Frontend

Vue 3 mit TypeScript, Vite und Tailwind CSS. Live-Status per Server-Sent Events, PDF- und XML-Vorschau, Korrekturformular mit Validierung.

Qualität & Betrieb

JUnit 5 und Testcontainers gegen echte PostgreSQL, Vitest, Playwright-Tests für den ganzen Freigabeprozess im Browser. Docker, GitHub Actions, Caddy mit HTTPS. Der XML-Parser ist gegen XXE gehärtet, Logins sind gegen Durchprobieren gedrosselt.

Die API ist mit OpenAPI dokumentiert: Swagger UI öffnen.

FAQ

Häufige Fragen

Was ist Belegfluss?

Belegfluss ist ein Rechnungseingang für kleine Unternehmen. Eingangsrechnungen werden hochgeladen, automatisch ausgelesen und geprüft und anschließend im Vier-Augen-Prinzip freigegeben und gebucht. Es ist ein Portfolio-Projekt von Omar Fourati mit öffentlichem Quellcode, kein kommerzielles Produkt.

Welche E-Rechnungsformate liest Belegfluss?

Belegfluss liest beide Syntaxen der europäischen Norm EN 16931: UBL 2.1 (XRechnung) und UN/CEFACT CII (XRechnung CII, ZUGFeRD und Factur-X). Die Rechnung kann als XML-Datei hochgeladen werden oder als PDF mit eingebettetem XML (ZUGFeRD).

Braucht jede Rechnung KI?

Nein. E-Rechnungen werden exakt aus dem XML übernommen, ohne KI und ohne Kosten. Nur PDFs ohne E-Rechnungsdaten werden von einem Sprachmodell ausgelesen, Scans ohne Textebene von einem Vision-Modell.

Welche Prüfungen macht Belegfluss automatisch?

Belegfluss warnt bei möglichen Dubletten, wenn Netto plus Umsatzsteuer nicht den Bruttobetrag ergibt, bei ungewöhnlichen Umsatzsteuersätzen, bei ungültiger IBAN-Prüfziffer und wenn ein Lieferant plötzlich eine andere IBAN angibt. Wer eine Rechnung mit Warnungen freigibt, muss einen Kommentar schreiben.

Was bedeutet Vier-Augen-Freigabe in Belegfluss?

Weder die Person, die eine Rechnung hochgeladen hat, noch die Person, die zuletzt Felder korrigiert hat, darf sie freigeben. So kann niemand allein eine IBAN ändern und die Zahlung freigeben. Jeder Schritt landet im Audit-Trail.

Mit welcher Technik ist Belegfluss gebaut?

Backend mit Java 21, Spring Boot 3, Spring AI, Spring Security (JWT), PostgreSQL und Flyway, Frontend mit Vue 3, TypeScript und Tailwind CSS. Getestet mit JUnit 5, Testcontainers, Vitest und Playwright, ausgeliefert per Docker und GitHub Actions.

Kann ich mich bei Belegfluss registrieren?

Nein, eine offene Registrierung gibt es bewusst nicht. Wie in einer echten Firma legt der Admin die Benutzer mit ihrer Rolle an – nur so funktioniert die Vier-Augen-Freigabe.
